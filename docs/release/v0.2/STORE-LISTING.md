## 3. 完整说明

**限制**：最多 4000 字符。

```
CleanGuard 是一款在手机本机运行的存储占用分析工具。它帮你先看清空间被什么占用了，再由你决定是否处理。

■ 先看懂，再动手
CleanGuard 不会用恐吓式文案催促你清理。每个建议都会说明它为什么被建议查看，但「建议查看」不等于「可以安全删除」——是否可处理始终由独立的本地安全规则决定。你始终看到完整理由，再自己决定。

■ 全部在本机完成
CleanGuard 没有网络权限，不具备联网能力。应用不含分析、广告或崩溃上报 SDK，不上传你的文件、路径、哈希或已安装应用列表。扫描、分类、哈希与历史记录全部在你的设备上处理。

■ 只读索引，不读画面
常规扫描只读取系统媒体索引中的文件名、类型、大小、修改时间与目录，不读取照片或视频的内容，不读取 EXIF 与位置信息。

■ 重复文件由你确认
进入「重复文件」页面时，CleanGuard 会在本机流式计算 SHA-256，用来确认候选文件的内容是否完全相同。计算过程不保存文件副本，不产生缩略图。结果只是建议，需要你逐项决定保留哪一份。

■ 不是一键清理
CleanGuard 不提供全局一键删除。风险等级为 DANGER 或 UNKNOWN 的条目无法进入处理流程，REVIEW 条目默认不选中。

■ 走系统回收站，不永久删除
被选中的项目会移入 Android 系统回收站，保留时长由系统决定，移入通常也不会立即释放物理空间。每次操作都先经过应用内确认，再经过 Android 系统确认界面。

■ 不会动你的下载目录
你通过系统目录选择器授权的下载目录只会被读取，CleanGuard 不会删除或修改其中任何文件。

■ 你可以只给部分权限
在 Android 14 及以上系统中，你也可以选择只授权部分照片和视频，CleanGuard 会明确标注当前统计仅基于你的授权范围。拒绝权限不会导致应用无法使用。

■ 恢复中心只管自己的事
「恢复中心」只显示并恢复由 CleanGuard 移入系统回收站的项目。它无法恢复你在系统相册中自行删除的文件。

■ 不是 AI 识图
CleanGuard 不识别相似图片或近似视频。它只确认内容完全相同的重复文件。建议依据是文件大小、修改时间、目录与文件类型，而不是画面内容。

■ 本机历史
扫描历史、空间趋势与应用占用变化都保存在设备本地，你可以自行设置保留次数，也可以随时清除。应用数据不参与云备份，也不参与设备迁移。
```

**字符数**：约 1150 字符 / 上限 4000

### 建议截图清单

按 Play 商店的转化惯例，首页放最强卖点：

1. **首页总览** —— 已用/可用空间、空间分类、权限状态（主打「先看懂」）
2. **扫描结果与建议** —— 建议列表及解释（主打「可解释」，注意截图中要能看到推荐等级与安全等级的区分说明）
3. **重复文件确认页** —— 显示「默认没有选择任何文件」的提示（主打「由你确认」）
4. **清理前确认页** —— 显示允许动作与风险等级
5. **权限中心** —— 显示每项权限的用途与影响（主打「最小权限」）
6. **空间趋势** —— 扫描历史

### 截图注意事项

- **不要**在截图中出现真实用户照片、文件名、路径或联系方式
- 需要素材时用无隐私的演示数据
- 截图中不要出现「一键清理」类按钮
- 权限中心截图能显著降低审核疑虑，建议保留

## 8. 不得出现在商店文案中的表述

| ❌ 禁用表述 | 原因 |
|---|---|
| 一键清理 / 深度清理 / 加速手机 | 无此功能，且属于误导性宣称 |
| 释放 XX GB 空间 | 移入回收站通常不立即释放物理空间，无法保证 |
| 智能 AI 识别 / 智能清理 | 无 AI 识图能力；建议基于规则而非智能 |
| 相似照片 / 相似图片清理 | 只做字节完全相同的重复确认 |
| 保护您的隐私 securely | 英文营销词与中文文案混用，且不构成具体承诺 |
| 回收站已删除文件恢复 | 仅能恢复自己移入的，不能恢复用户自行删除的 |
| 完美 / 最安全 / 第一 | 无法验证的最高级宣称，Play 政策明确禁止 |
| 清理其他应用缓存 | 明确不做（`StorageInsightsScreen.kt:224` 已声明） |
