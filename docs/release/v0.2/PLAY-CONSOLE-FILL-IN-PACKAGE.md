### 用途说明原文（直接复制）

```
CleanGuard 是一款本地存储占用分析工具。其「空间洞察」功能需要向用户展示各应用的
汇总存储占用，以帮助用户判断哪些应用占用了过多空间。Android 系统仅在用户于系统设置
中手动授予「使用情况访问」后才向应用提供此数据。

CleanGuard 的实现约束如下：

1. 不会尝试绕过该限制。应用不包含任何 Root、Shell、Shizuku 或隐藏 API 调用。
2. 不在应用启动时请求。应用启动不弹出任何权限对话框；仅当用户主动点击「应用占用」
   相关入口时，才引导用户前往系统设置手动开启。
3. 不申请 QUERY_ALL_PACKAGES。应用的 <queries> 仅声明 MAIN/LAUNCHER 意图，
   因此只能枚举有桌面图标的应用。
4. 只读取汇总字节数。每项仅取系统提供的应用占用（appBytes）、数据占用（dataBytes）、
   缓存占用（cacheBytes）三个总量，不读取任何应用内部的具体文件。
5. 不清理其他应用的缓存。应用不提供也不执行任何针对其他应用的清理操作，
   该行为在「空间洞察」页面上有明确声明。
6. 不传输数据。应用未声明 INTERNET 权限，不具备网络能力，所有数值仅在应用内展示。

用户拒绝或未开启该权限时，应用仍可正常打开与扫描，仅「应用占用」相关功能不可用，
界面会明确说明影响范围。
```

### 注意

- **不要**在说明里写「我们不收集数据」这种笼统话。要写清**具体读了什么、没读什么**。
- 一定要保留第 4、5 条（只读汇总字节数、不清理其他应用缓存）—— 这是审核最关心的两点。

### 三个高频错误

**① 看到「文件与文档」就勾「收集」**
❌ 错。Play 的「收集」定义是数据被**传输离开设备**且开发者/第三方可访问。CleanGuard 从不传输。
✅ 选「不收集」。

**② 勾选「数据已加密传输」**
❌ 错。应用没有传输行为。勾这一项等于暗示存在数据传输。
✅ 选「不适用 / 无数据传输」。

**③ 声明「收集匿名使用统计用于改进产品」**
❌ 错。应用无任何日志、埋点、崩溃上报实现。
✅ 不勾任何收集项。

```
CleanGuard 没有网络权限，无法传输任何数据。应用仅在本机读取 MediaStore 索引元数据
（文件名、类型、大小、修改时间、相对目录）并在本地数据库中保存分析结果，用于在应用内
```

# 第五步：商店信息（Store presence）

**路径**：`Play 管理中心 → 商店 → 商店信息 → 主要商店信息`

### 直接复制的文案

**应用名称**（30 字符上限）
```
CleanGuard: 空间分析助手
```

**简短说明**（80 字符上限）
```
看懂你的存储占用，只处理你确认的内容。不联网，不上传。
```

**完整说明**（4000 字符上限）
```
CleanGuard 是一款在手机本机运行的存储占用分析工具。它帮你先看清空间被什么占用了，再由你决定是否处理。

■ 先看懂，再动手
CleanGuard 不会用恐吓式文案催促你清理。每个建议都会说明它为什么被建议查看，但「建议查看」不等于「可以安全删除」——是否可处理始终由独立的本地安全规则决定。你始终看到完整理由，再自己决定。

■ 全部在本机完成
CleanGuard 没有网络权限，不具备联网能力。应用不含分析、广告或崩溃上报 SDK，不上传你的文件、路径、哈希或已安装应用列表。扫描、分类、Hash 与历史记录全部在你的设备上处理。

■ 只读索引，不读画面
常规扫描只读取系统媒体索引中的文件名、类型、大小、修改时间与目录，不读取照片或视频的内容，不读取 EXIF 与位置信息。

■ 重复文件由你确认
进入「重复文件」页面时，CleanGuard 会在本机流式计算 SHA-256，用来确认候选文件的内容是否完全相同。计算过程不保存文件副本，不产生缩略图。结果只是建议，需要你逐项决定保留哪一份。

■ 不是一键清理
CleanGuard 不提供全局一键删除。风险等级为 DANGER 或 UNKNOWN 的条目无法进入处理流程，REVIEW 条目默认不选中。

■ 走系统回收站，不永久删除
被选中的项目会移入 Android 系统回收站，保留时长由系统决定，移入通常也不会立即释放物理空间。每次操作都先经过应用内确认，再经过 Android 系统确认界面。

■ 不会动你的下载目录
你通过系统目录选择器授权的下载目录只会被读取，CleanGuard 不会删除或修改其中任何文件。

■ 你可以只给部分权限
在 Android 14 及以上系统中，你也可以选择只授权部分照片和视频，CleanGuard 会明确标注当前统计仅基于你的授权范围。拒绝权限不会导致应用无法使用。

■ 恢复中心只管自己的事
「恢复中心」只显示并恢复由 CleanGuard 移入系统回收站的项目。它无法恢复你在系统相册中自行删除的文件。

■ 不是 AI 识图
CleanGuard 不识别相似图片或近似视频。它只确认内容完全相同的重复文件。建议依据是文件大小、修改时间、目录与文件类型，而不是画面内容。

■ 本机历史
扫描历史、空间趋势与应用占用变化都保存在设备本地，你可以自行设置保留次数，也可以随时清除。应用数据不参与云备份，也不参与设备迁移。
```
