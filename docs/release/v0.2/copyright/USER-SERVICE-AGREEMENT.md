## 二、服务内容

### 2.1 服务范围

本应用为**完全在用户设备本地运行**的存储占用分析工具，提供以下功能：

1. **存储占用分析**：读取系统媒体库索引，展示设备存储容量与分类占用情况
2. **文件分类**：按大文件、较旧文件、录屏、截图、旧安装包等维度归类候选项
3. **重复文件辅助确认**：通过文件内容哈希计算，辅助用户确认内容完全相同的文件
4. **空间趋势记录**：在设备本地记录历史扫描结果，用于展示占用变化趋势
5. **清理辅助**：在用户逐项选择并确认后，将选中的媒体项目移入 Android 系统回收站

### 2.2 服务的提供方式

- 本应用**不具备网络访问能力**，未申请网络权限
- 所有分析、分类、哈希计算与历史记录均在您的设备本地完成
- 本应用**不上传**您的任何文件、文件内容、文件路径、哈希值或已安装应用信息
- 本应用不包含广告、统计分析或崩溃上报功能

### 2.3 服务的中断

出现以下情形时，本服务的可用性可能受到中断，且运营方不承担因下列原因导致的服务中断而产生的一切责任：

1. 设备电量不足、存储空间不足或系统资源紧张
2. 用户的操作系统版本低于本应用支持的最低版本
3. 用户主动卸载、禁用或限制本应用的相关权限
4. 智能手机厂商对系统权限或后台行为的策略调整
5. 不可抗力（包括自然灾害、战争、疫情、政府行为、电信网络中断等）

## 五、关于清理功能的重要提示

为避免误解，请特别注意以下事项：

### 5.1 本应用不提供永久删除

本应用**不具备永久删除文件的能力**。经您确认并通过系统确认界面后，被处理的项目将被移入 **Android 系统回收站（Trash）**。

- 回收站的保留时长由 Android 系统决定，您可在系统设置中查看与清空
- **移入回收站通常不会立即释放物理存储空间**，实际释放时机由系统决定
- 本应用内的「恢复中心」仅显示并恢复**由本应用移入系统回收站**的项目，无法恢复您在系统相册或其他应用中自行删除的文件

### 5.2 风险分级

本应用对候选项采用独立的安全规则进行风险评估，输出四个等级：

| 等级 | 含义 |
|---|---|
| DANGER | 属于系统或应用私有数据区域、数据库、凭据等，删除风险高 |
| REVIEW | 需要人工判断，例如较大的文件或内容完全相同的重复项 |
| SAFE | 相对安全的候选项 |
| UNKNOWN | 信息不足，无法判定 |

**DANGER 与 UNKNOWN 等级的项目不提供任何处理动作；REVIEW 等级的项目默认不选中。** 界面上的「建议查看」等优先级标签仅表示推荐排序，**不代表可以安全删除**，是否可处理始终以安全规则为准。

### 5.3 您的责任

您在处理任何文件前应自行确认该文件的重要性。本应用展示的分类与建议基于文件大小、修改时间、目录与文件类型等信息，**不构成对文件内容或重要性的判断**。

因您依据本应用的提示作出处理决定而产生的后果，由您自行承担。

### 5.4 下载目录的处理

对于您通过系统目录选择器授权的下载目录，本应用**仅进行只读扫描，不会删除或修改该目录中的任何文件**。
